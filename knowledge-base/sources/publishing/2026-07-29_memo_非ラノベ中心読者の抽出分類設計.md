# 非ラノベ中心読者の抽出分類設計

## 要約
人気ラノベの読者のうち「普段はラノベ界隈に属していない層（越境読者）」が日常的に何を消費しているかを把握するための調査設計。核心は、全ユーザーをいきなり人物分類せず、①対象作品の読者である確度を判定 → ②読者確度の高い人だけをラノベ外の属性で分類、の2段階に分けること。混ぜるとアニメ視聴者・キャンペーン応募者・出版関係者が紛れ込み結果が歪む。全体フローは「収集 → 読者確度判定 → 出版/創作関係者の分離 → ラノベ親和度の判定 → LN-Outside層の抽出 → 関心・行動のAI分類 → 個人でなく集団の構成比として集計」。読者認定は0/1でなく証拠別のスコア（読了明記・具体的感想が最強、公式フォローは+1、いいね+0.5、キャンペーン反応は0）。収集は公式投稿のいいねより「作品名＋読了/読んだ/買った」の自発投稿が最重要で、投稿種別ごとに集まる層が偏る（新刊告知＝既存読者、アニメ映像＝アニメ層、プレゼント企画＝懸賞層、重版報告＝業界関係者）ため複数種類から集める。AI処理は投稿を機械的に30〜50件へ絞ったうえで「観測事実の抽出」と「属性への分類」の2回に分離し、人物像の自由生成を避ける。属性は年齢・性別・職業ではなく、主要コンテンツ領域／消費行動／流入経路／ラノベとの距離の多軸で保持する。アニメ化作品は除外せず、非アニメ化ヒット作・アニメ化直後・アニメ終了後の3群に分けて別集計。媒体はX自発投稿が最重要、読書メーター・ブクログは活字読者内の越境層、AniListはアニメ経由・海外、Amazonレビューは評価理由、pixivは創作コア層の分析に向く。

## 学び・発見
- **読者認定は0/1ではなくスコア。** 公式アカウントのフォローやいいねは「読者確定」ではなく候補を残すフィルターに留める。フォロワーにはアニメのみ・声優目的・懸賞目的・業界関係者・離脱者が混在する。
- **いいねユーザーより「作品名＋読了/購入」の自発投稿者が本命。** 読者である証拠が強く、普段の投稿から読書外の関心領域が分かり、公式をフォローしていない越境読者も拾える。
- **AIに人物像を自由生成させない。** 「事実の構造化抽出」と「属性分類」を別プロンプトに分けないと、少数の投稿から過剰推測が起きる。前処理でノイズ投稿（単純リポスト・挨拶・キャンペーン応募・URLのみ）を機械的に落としてから渡す。
- **属性はデモグラフィックでなく施策に使える軸で定義する。** 関心領域・消費行動・流入経路・ラノベとの距離を多軸で持つ方が、精度も利用価値も高い。
- **比較対象なしでは結論が出せない。** 1作品だけを見ると、その読者属性が「人気作特有」なのか「ラノベ全般」なのか判別できない。

## 読者確度スコア

| 観測内容 | 配点 |
|---|---|
| 対象作品の読了・具体的感想 | +5 |
| 対象作品の購入報告 / 続巻の購入・予約 / 読書サービスへの読了登録 | +4 |
| 作品の具体的内容への言及 / 原作を読んでいると明記 | +3 |
| 公式アカウントをフォロー | +1 |
| 公式投稿への通常いいね | +0.5 |
| キャンペーン投稿への反応 | +0 |

判定：5点以上=確度「高」／3〜4.5=「中」／1〜2.5=候補／1点未満=対象外

## ラノベ親和度の3区分
- **LN-Core**：普段からラノベを継続的に読む（複数作品への継続投稿、レーベル・発売日を追う、プロフィール記載）
- **LN-Adjacent**：漫画・アニメ中心だが話題作やアニメ原作のラノベも読む（なろう系言及、アニメ原作小説を複数）
- **LN-Outside**：ラノベへの日常的接触はほぼ見えないが対象作品は読んでいる ← **最重要ターゲット**

弱い証拠（対象1作品だけの言及、公式1つのフォロー）でCore判定しないこと。

## 分類の4軸（多軸で保持）
- **A. 主要コンテンツ領域**：一般文芸／ミステリー・SF／漫画／アニメ／ゲーム／ソシャゲ／VTuber・配信／映画／ドラマ／音楽・アイドル／声優／TRPG・ボードゲーム／創作活動
- **B. 消費行動**：話題作を広く追う／特定IPを深く追う／アニメ・漫画から原作へ移行／SNS口コミで発見／ランキング・受賞基準／作家買い／キャラ軸・世界観軸・テーマ軸
- **C. 流入経路**：原作／アニメ／コミカライズ／口コミ・バズ／書店・ランキング／作家・イラストレーター
- **D. ラノベとの距離**：LN-Core / Adjacent / Outside / 判定不能

例：主要=ゲーム、副=アニメ・VTuber、行動=話題作横断型、距離=LN-Outside、流入=アニメ経由

## AI処理の2段階
1. **事実抽出**（推論させない）：言及コンテンツ（タイトル・媒体・行動・頻度）、観測された活動、書籍関連行動をJSONで構造化
2. **属性分類**：抽出済み事実から `target_work_reader_confidence` / `light_novel_affinity` / `primary_external_segment` / `probable_entry_route` / `confidence` / `evidence_post_ids` を出力

取得範囲はプロフィール・固定ポスト・直近100〜200件から、分析価値の高い30〜50件に絞る。

## 出版・創作関係者の扱い
除外ではなく3分類：`industry_professional`（出版社・編集・書店・商業作家）／`creator_amateur`（同人・Web小説・二次創作）／`general_reader`。アマチュア創作者は「ラノベ外の創作者層に届いた証拠」として価値があるため残す。プロフィールの正規表現（編集／書店員／校閲／レーベル／献本 等）だけでなく、直近投稿の「担当作」「重版」「弊社」「書店勤務」もAIに確認させる。

## 媒体評価

| 媒体 | 読んだ証拠 | 読書外の属性 | 役割 |
|---|---|---|---|
| X・作品名の自発投稿 | ◎ | ◎ | 最重要 |
| X・公式投稿いいね | △ | ◎ | 候補者収集 |
| X・公式フォロワー | △ | ◎ | 補助 |
| 読書メーター | ◎ | △ | 活字読者内の分類 |
| ブクログ | ○〜◎ | △ | 活字読者の補完（公開設定ユーザーのみ、取得条件の確認要） |
| AniList | ○ | ○ | アニメ経由・海外（国内一般層には偏る） |
| Amazon等レビュー | ○ | △ | 「どういう人か」でなく評価理由の分析 |
| pixiv | △ | ○ | 創作行動まで起こすコア層 |

読書メーターとXは別集団として結果を出す。前者は「活字読者のうちどの読書家層が読んだか」、後者は「別文化圏の人がなぜ接触したか」が分かる。読書メーターで特に価値が高いのは「対象作品を読了 AND 他のラノベ登録がほぼない AND 一般文芸・ミステリーを多数読んでいる」ユーザー。

## 調査構成
- **調査A：非アニメ化ヒット作品** — アニメの力を使わずどの文化圏へ越境したか（今回の目的に最適）
- **調査B：アニメ化作品** — 放送前／放送中／終了後／続刊発売時に分けて取得し、誰が入り誰が原作を継続購入したか
- **調査C：比較対象** — 対象人気作 vs 同ジャンルの小規模作 vs 異ジャンルの人気ラノベ

## 当初案からの修正4点
1. 公式フォローを読者確定にせず、確度スコアの一要素にする
2. いいねユーザーでなく「作品名＋購入・読了」の自発投稿者を中心にする
3. AIに人物像を自由生成させず、事実抽出と分類の2段階にする
4. 属性を年齢・職業でなく、関心領域・消費行動・ラノベ距離・流入経路で定義する

到達したい結論の形：「普段ラノベを読まない層ではゲーム中心層と一般ミステリー読者が多く、前者はキャラクター・SNS口コミ経由、後者はストーリー評価・書店ランキング経由で入っている」
