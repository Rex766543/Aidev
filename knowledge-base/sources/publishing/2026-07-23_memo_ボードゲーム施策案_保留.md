# ボードゲーム施策案_保留

## 要約
ラノベIPを使ったボードゲーム施策の検討メモ。現時点では優先度を下げて保留と判断。対象はボードゲーム会社の社員ではなく、個人・同人サークル・商業化を目指すインディー制作者。この層の主な欲求は既存IPの利用ではなく「自分のゲーム性を形にして遊んでもらうこと」であり、ラノベ側が提供できる価値は世界観・キャラクター・イラスト素材・商品化機会。実施する場合はオンライン試作→公募→専門家評価→テストプレイ→上位作の物理化という流れになるが、制作負荷が高く認知拡大も遅い。ボードゲーム会社を巻き込むなら、弱いIPだけでは動機にならず、出版社側が開発費・素材・販路・宣伝を持つ必要がある。性質としては認知施策ではなく、発売後のIP展開・コアファン形成・作品世界の長期活用に向く。

## 学び・発見
- **ボードゲーム施策は認知獲得フェーズの施策ではない。** 制作負荷が高く拡散が遅いため、発売後のIP展開・コアファン深耕・世界観の長期活用フェーズに位置づけるべき。
- **インディー制作者の一次動機は自分のゲーム性の実現であり、IP利用ではない。** 無名IPは創作報酬として機能しないため、商品化機会（物理化・販路）という機会報酬で交換関係を成立させる必要がある。
- **法人（ボードゲーム会社）を動かすコストは高い。** 弱いIPでは先方の動機が立たず、開発費・素材・販路・宣伝をすべて出版社側が負担する前提になる。

## 施策の骨子（実施する場合）
1. オンライン試作
2. 公募
3. 専門家評価
4. テストプレイ
5. 上位作の物理化（商品化）

## 保留理由
- 制作負荷が高い（参加者・運営双方）
- 認知拡大への寄与が遅い
- 法人巻き込み時は出版社側の負担（開発費・素材・販路・宣伝）が大きい

## 前提フレームワーク（報酬5類型）
施策設計は作品起点ではなく「その人が普段何を欲しがっているか／何が不足しているか／参加で何を持ち帰れるか」から考える。報酬は①金銭（出演料・制作費・賞金・売上分配。低予算では人数を広げにくい）②実績（商業クレジット・ポートフォリオ。駆け出し層には金銭以上に効くことも）③認知（公式による紹介。公式が小さいと弱い）④機会（採用・継続案件・書籍化など将来への入口）⑤創作（自分では用意できない素材・設定で表現できること。素材の魅力が前提）の5類型。
