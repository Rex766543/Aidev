# 無名作品クリエイター参加の報酬設計

## 要約
無名ラノベで「作品が好きだから作る」型の自発的ファン創作は期待できない。参加者が動くのは自分の活動に得があるときであり、施策は作品起点ではなく「その人が普段何を欲しがり、何が不足していて、参加で何を持ち帰れるか」から設計する。報酬は①金銭②実績（商業クレジット・ポートフォリオ）③認知（公式による紹介）④機会（継続案件・採用への入口）⑤創作（自分では用意できない素材・設定で表現できること）の5類型に整理でき、職種（声優志望・イラストレーター・動画編集者・VTuber・音楽系・コスプレイヤー・小説家志望・考察系・ハンドメイド系）ごとに効く報酬と効かない報酬が異なる。共通して弱いのは「公式リポスト」「書籍プレゼント」「採用の可能性」といった曖昧・低価値な報酬で、強いのは実務に近い成果物・明確な保証範囲・金銭や広告費の投下・継続起用の道筋。参加者本人だけでなくそのファン側にも利益（推しの露出・投票参加・限定コンテンツ）が必要。結論として、初期は「仕事・実績・コンテンツ・成長機会を提供する交換関係」として設計し、認知とファンが育ってから純粋なファン創作へ移行する。

## 学び・発見
- **無名作品では作品愛はゼロと見なして設計する。** 参加者の利益 ＝ 即時報酬＋実績＋露出＋将来機会−制作負担−権利リスク。この式が正にならない限り参加は起きない。
- **「公式に紹介します」は公式が小さければ報酬にならない。** 参加者の方がフォロワーを持つ場合、逆に「広告費であなたの作品を広げる」「有償案件候補にする」「商業実績として使ってよい」の方が強い。
- **「採用の可能性」は宝くじ。** 採用人数・支払額・掲載先・次の仕事への接続を具体化し、落選者にも成果物（ポートフォリオ利用可の素材等）が残る設計にする。
- **参加者のファンにも報酬が要る。** 参加者が動いても、そのファンが作品に関心を持つ仕掛け（推しの登場・投票・限定コンテンツ）がなければ認知は広がらない。

## 報酬の5類型
1. **金銭報酬** — 出演料・制作費・賞金・売上分配。明快だが低予算では人数を広げにくい
2. **実績報酬** — 商業作品のクレジット・ポートフォリオ。駆け出し層には金銭以上に効くことがある
3. **認知報酬** — 公式アカウントでの紹介。公式自体が小さいと弱い
4. **機会報酬** — 採用・継続案件・書籍化など将来への入口
5. **創作報酬** — 自分では用意できない素材・設定・キャラで表現できること。素材自体の魅力が前提

## 職種別の有効報酬（要点）

| 職種 | 最も効く報酬 | 弱い報酬の典型 |
|---|---|---|
| 声優志望 | 役名付きクレジット、公式PV採用、音源のポートフォリオ利用可、少額でも出演料 | リポスト、書籍1冊、優勝者だけ採用 |
| イラストレーター | 「公式企画参加作品」扱い＋実販促物（特典カード・POP）採用＋名前明記 | ハッシュタグ投稿、無断二次利用、「推しを自由に描いて」 |
| 動画編集者 | **自分の動画に公式が広告費をかける**（数万人配信の実績になる）、制作費支払い | リポストのみ、素材が表紙1枚、数字が見えない |
| VTuber・配信者 | **配信が面白くなるネタ**（視聴者投票・限定謎・陣営分け）、有償案件、本人の作中登場 | 書籍提供のみ、感想配信依頼 |
| 音楽系（歌い手・ボカロP） | 制作費・収益分配、公式音源登録、**「宣伝曲」でなく本人の新曲として成立**させる | 権利全譲渡、制作費なし、小さいクレジット |
| コスプレイヤー | 衣装費か撮影機会のどちらかを公式負担、公式認定、イベント出演 | 自費制作＋リポストのみ |
| 小説家志望 | **編集者に読まれる保証**（全応募に短評・上位20作にコメント等、範囲明示）、公式掲載 | 「掲載の可能性」「編集部が拝見します」 |
| 考察系 | **先行性・独占性**（先行試読・限定資料・作者の答え合わせ）。金銭なしでも動き得る | 発売後に自由に考察、正解を示さない |
| ハンドメイド系 | 材料費支給、買い取り、**販売許諾・ロイヤリティ**（ただし権利管理が複雑化） | 無償制作＋販売禁止 |

## 設計の勘所
- 応募多数で採用1名の構図は大半が「無料労働」で終わる。全員に成果物が残る形（公開可能素材＋複数人紹介＋一部有償継続起用）にする
- 動画制作者の参加ラインの目安：素材提供＋ポートフォリオ利用可＋公式広告採用＋採用費3万円＋継続案件候補。逆に「無償制作＋リポスト＋優秀者に書籍」ではファン以外は動かない
- （補足）この構造はUGCマーケティング一般における「内発的動機（作品愛）が使えない立ち上げ期は外発的インセンティブで交換関係を成立させ、認知形成後に内発的動機へ移行する」という段階設計に相当する

## 移行ステップ
1. 立ち上げ期：仕事・実績・成長機会を提供する交換関係として施策設計
2. 認知が高まりファンが生まれた後：純粋なファン創作（作品愛ベース）へ移行
